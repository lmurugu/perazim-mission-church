# Design mockups (not part of the live site)

Source of the Perazim website design mockups made on the Design canvas
(https://claude.ai/artifact/C4JjfiqUWJFLDbYYFmUpVj, private). Nothing here is
published or linked from the website; `design/` is excluded from the Pages build.

- `Main`, `Live`, `Editorial`: first home page directions (A, B, C).
- `Dark`, `Light`: palette round (deep purple #2A0F33, royal purple #681A7D, orange #E17D2F).
- `Frosted` (home), `FrostedVisit`, `FrostedSermons`, `FrostedMinistries`, `FrostedGive`,
  `FrostedAbout`, `FrostedContact`: the light frosted glass design with painted heroes,
  burger menu and motion.
- `HomeJourney`, `HomePaths`, `HomePanels`: three interactive, immersive home page ideas.
- `canvas.json`: layout of the boards on the canvas.
- `paintings/`: the six Bible-story paintings used as hero images.

The `.dc.html` files refer to images as `/_blob/<id>` (canvas uploads), so they only
render on the canvas. Map: prodigal-son, sermon-on-the-mount, good-samaritan,
five-loaves-two-fish, calling-the-disciples, jesus-at-the-door.
